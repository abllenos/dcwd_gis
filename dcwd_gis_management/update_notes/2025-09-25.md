## Enhancements
### 1. Table Column Sorting Added
| Page | Columns Now Sortable | Sorter Type |
|------|----------------------|-------------|
| Classification | ID, Layer Name, Class Name | Numeric ID; string localeCompare |
| Class | ID, Date Inserted | Numeric ID; timestamp compare |
| Layer | ID, Date Inserted | Numeric ID; timestamp compare |

Implementation notes:
- Numeric IDs: `(a, b) => a.id - b.id` (IDs coerced to number during normalization)
- Strings: `a.layerName.localeCompare(b.layerName)` / `a.className.localeCompare(b.className)` (base locale, stable)
- Dates: `new Date(a.dateInserted).getTime() - new Date(b.dateInserted).getTime()` safeguarded by simple existence checks
- All sorter functions are pure and side‑effect free to avoid unnecessary MobX reactions.
